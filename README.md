# DRAFT ROOM — 브롤스타즈 조합 연구소

맵을 고르면 그 맵에 맞는 브롤러 조합을 추천해 주는 단일 HTML 페이지입니다. 비공식 팬메이드 도구입니다.

## 실행

`index.html`을 브라우저로 열면 됩니다. 인터넷 연결이 필요합니다(맵·브롤러·통계 데이터를 실시간으로 불러옵니다).

한 번 정상적으로 불러온 데이터는 브라우저에 저장해 둡니다. 이후 API가 응답하지 않으면 저장본으로 페이지를 띄우고, 상단에 `API 응답 없음 · 저장본 사용`과 저장 시각을 표시합니다.

## 데이터

- 맵·브롤러 목록: [Brawlify](https://brawlify.com) 공개 API
- 현재 맵 풀(최근 4주 실전 기록이 있는 맵), 맵별 브롤러 승률 효과, 맵 이미지: [BrawlTime](https://brawltime.ninja)
- 한국어 맵·브롤러 이름: 게임 텍스트 추출본([psh1234567890/brawl_status_kr](https://github.com/psh1234567890/brawl_status_kr)) + BrawlTime
- Brawlify 목록에 아직 없는 신규 맵은 `NEW_MAPS`에 직접 넣어 두었습니다.

## 추천 방식

- 맵 이미지를 타일 단위로 분석해 벽·부쉬 비율, 시야선, 중앙 개방도 등을 계산합니다.
- 브롤러별 프로필(사거리, 체력, 딜, 기동, 군중 제어, 벽 파괴, 투척, 회복, 포지션)과 모드별 가중치, 실전 승률 효과를 합쳐 개인 적합도를 냅니다.
- 상위 후보로 가능한 조합을 모두 계산해 역할 밸런스, 시너지, 카운터 내성, 상대 픽 대응 등을 반영한 점수로 정렬합니다.

종합 점수와 추정 승률은 이 페이지가 계산한 값이며 공식 통계가 아닙니다.

## 테스트

실제 API로 페이지를 띄워 주요 동작(데이터 로딩, 고정 픽이 있을 때의 대안 조합, 모드별 역할 배정, 밴·상대 픽 처리, API 장애 시 저장본 폴백)을 확인하는 스모크 테스트입니다. Playwright와 Chromium, 인터넷 연결이 필요합니다.

```bash
npm install playwright && npx playwright install chromium
node tests/smoke.cjs
```

## 데이터 갱신

브롤러 프로필(`P`), 한국어 이름(`KO`, `MAP_KO`, `MAP_KO_ID`), 신규 맵(`NEW_MAPS`)은 직접 넣은 값입니다. 프로필이 없는 신규 브롤러는 클래스 기본값으로 계산되며, 화면에 `추정 프로필`로 표시되고 개인 적합도 카드 아래에 목록이 나옵니다. 그 목록에 브롤러가 보이면 `P`에 프로필을 추가하세요.
